# 📊 Sales Data Cleaning & Monthly Analysis Project

## 📌 Project Overview
This project focuses on cleaning raw sales data, handling formatting issues, removing invalid records, and performing Exploratory Data Analysis (EDA) to understand monthly category performance.

## 🛠️ Tools & Libraries Used
- **Python** (Pandas, Matplotlib, Seaborn)
- **Jupyter Notebook**
- **Excel** (Final Output Export)

## 🧹 Key Steps Performed
1. **Data Cleaning:** Corrected spelling mistakes, formatted dates (`datetime`), and handled invalid rows.
2. **Data Aggregation:** Grouped sales data by `order_month` and `Product_Category` to analyze performance trends.
3. **Data Visualization:** Generated grouped bar charts showing category sales across months.
4. **Exporting Results:** Exported the cleaned dataset to a structured `.xlsx` Excel file for business presentation.
